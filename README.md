# 🎓 Student Performance Analytics Dashboard

## 📌 Project Overview

The Student Performance Analytics Dashboard is an interactive Power BI project designed to analyze student academic performance across multiple dimensions such as gender, ethnicity, parental education level, and test preparation status.

The dashboard provides meaningful insights into student achievement patterns and helps educators, institutions, and analysts make data-driven decisions to improve academic outcomes.

---

## 🚀 Features

### KPI Cards
- Total Students
- Average Math Score
- Average Reading Score
- Average Writing Score
- Average Score Percentage

### Interactive Filters
- Ethnicity
- Gender
- Parental Education
- Test Preparation

### Visualizations
- Student Performance by Ethnicity
- Performance Distribution by Gender
- Score Analysis by Parental Education
- Test Preparation Impact on Scores
- Ethnicity vs Parental Education Comparison
- Subject-wise Performance Analysis (Math, Reading, Writing)

---

## 📊 Dashboard Insights

### Academic Performance Analysis
- Compare student scores across different demographic groups.
- Identify performance trends based on parental education levels.
- Analyze the effectiveness of test preparation courses.

### Diversity & Inclusion Insights
- Explore score variations among different ethnic groups.
- Understand gender-based performance distribution.

### Subject Performance
- Compare Math, Reading, and Writing scores.
- Identify strengths and improvement areas across subjects.
